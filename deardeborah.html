Dear Deborah

A personalized friendship archive and scrapbook web application featuring custom dashboards, memories tracking, stats analytics and relationship management.

View GitHub Repository

Development Status & Features

Dear Deborah is a feature-rich, data-driven web application designed to act as a personal scrapbook and relationship manager. It handles complex data relations including custom friendship tiers, birthday trackers, memories mapping and statistical analytics.

The backend is built with Django, utilizing custom forms, SQLite and robust query filtering to ensure smooth organization and data retrieval.

Tech Stack

  • 🐍 Python & Django
  • 🗄️ SQLite Database
  • 📊 Custom Scrapbook UI & Dashboards
  • 🔐 Django Admin Integration
