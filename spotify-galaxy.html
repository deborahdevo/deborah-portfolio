Spotify Galaxy

An interactive music era visualizer combining user listening history, Spotify API integration and retro-futuristic aesthetics.

View GitHub Repository

Development Status & Vision

Spotify Galaxy is currently under active development. The project aims to bridge music data with immersive UI design, allowing users to explore their listening habits across different chronological and personal eras.

By leveraging OAuth 2.0 client authentication and the Spotify Web API, the application maps top tracks and artists into visual clusters resembling a galaxy of musical milestones.
